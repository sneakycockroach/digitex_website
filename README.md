The official website for Digitex, a creative studio in Mbale City, Uganda, located opposite FINCA Bank.

Services: Graphic Design · Branding · Photography · Software

Overview

A fast, minimal, mobile-first one-page website that presents Digitex's services and makes it easy for customers to get in touch. Visitors can request a quote, chat on WhatsApp or call with a single tap.

Features
Mobile-first, fully responsive layout
Minimal brand system: flat red, black and white, no gradients
Centered floating navigation with scroll-spy
Sections: Hero, Services, About, Work, Testimonials, Quote, Contact
Quote form that opens WhatsApp with the details prefilled
Floating WhatsApp chat button on every screen
Tap-to-call phone numbers
Scroll and hover animations, with reduced-motion support
Font Awesome icons

Getting Started

Prerequisites: Node.js 18 or newer

bash
# clone the repository
git clone https://github.com/<your-username>/digitex-website.git
cd digitex-website

# install dependencies
npm install

# start the development server
npm run dev

Open the local address shown in your terminal.

Build for Production
bash
npm run build
npm run preview

The production files are generated in the dist/ folder.

Deployment

Push the repository to GitHub.
Import it on your chosen host.
Set the build command to npm run build and the output directory to dist.
